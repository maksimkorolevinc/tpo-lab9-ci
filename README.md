# Автоматизированные тесты калькулятора

Лабораторная работа 9 по тестированию программного обеспечения.
В репозитории находятся собственный класс `Calculator` и 24 параметризованных
проверки из лабораторной работы 6. Публикуемые файлы перечислены в этом каталоге.

Запуск:

```sh
python -m pip install -r requirements.txt
python -m pytest -v
```

Workflow `.github/workflows/run-tests.yml` выбирает `ubuntu-latest`, устанавливает
Python 3.13 и pytest, затем выполняет все тесты. Запуск происходит на push,
pull request и вручную через workflow_dispatch. Успешный локальный прогон
сохраняется отдельно в материалах лабораторной. Результат GitHub Actions
подтверждается страницей конкретного запуска после публикации.
